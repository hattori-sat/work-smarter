# VS Code workflow

Work Smarter remains Markdown-first. Open the workspace in VS Code and run the bundled tasks (`GTD inbox`, `GTD daily dashboard`, and `Project schedule`) from **Terminal → Run Task**. The task commands are adapters; the Markdown/YAML documents and append-only events remain authoritative.

Install the CLI in the project environment, then set `WORK_SMARTER_WORKSPACE` when invoking it outside VS Code.
